# CoForge — Agentic Design System

A design operating system where AI agents produce research, journey maps, IA,
wireframes, UI, prototypes and handoff — under gates that make fabricated evidence
and off-system output impossible, not merely discouraged.

**Design-system state: RED** — a declared state, not a count. Tokens and brand
foundations exist; RED holds until L2 components land (ADR-011).

## The two prohibitions

1. Never create a component that is not in `design-system/component-index.json`.
2. Never write a user quote that is not in `research/evidence-ledger.json`.

Everything stronger is enforced by tools, hooks and CI — not by prose.

## Enforcement

| # | Layer | Implemented by |
|---|---|---|
| 1 | Impossible | `.claude/settings.json` + per-agent `tools:` |
| 2 | Blocked | `.claude/hooks/gate-b.py` (PreToolUse on Write\|Edit) |
| 2b | Backstop | `.claude/hooks/session-check.py` (Stop) — **Gate B does not fire on Bash writes** |
| 3 | Failed | `.github/workflows/ci.yml` → `validation/audit-system.py` |
| 4 | Visible | `validation/reports/*__system-audit.md` |
| 5 | Written | the two prohibitions above |

Layers 2 and 2b are exercised by `validation/test-gates.py`, not assumed — it plants
real violations down both paths and fails if either is let through.

## Regenerating

```bash
python3 validation/index-system.py        # .ai/index.json + .ai/index.md
python3 validation/rebuild-registry.py    # artifacts/_registry.json + ARTIFACTS.md
python3 validation/build-llms-txt.py      # design-system/llms.txt
python3 dashboard/build.py && python3 dashboard/render.py   # the dashboard
```

All generated by scanning. Never hand-edit their outputs.

## Checking

```bash
python3 validation/audit-system.py        # structure — what CI runs
python3 validation/audit-contracts.py     # redundancy, orphans, contracts vs tokens
python3 validation/test-gates.py          # does the gate actually block? both paths
```

Three different questions. `audit-system` asks whether the repo is *legal*;
`audit-contracts` asks whether the design system is *coherent*; `test-gates` asks
whether the enforcement *works*. A pass on one says nothing about the others.

## Building the token layer

```bash
python3 validation/build-token-axes.py --apply     # spacing, type, elevation, motion
python3 validation/align-dark-to-light.py --apply  # keep dark's key set == light's
python3 validation/adapters/carbon-react.py        # L2 components from @carbon/react
```

Each refuses to write unless its own checks pass, and each is idempotent.
