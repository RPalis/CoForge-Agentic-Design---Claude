01

Two faces, and only two

Anek Latin carries every word — display and body alike, so hierarchy comes from weight, not from a second family. Source Code Pro carries every number. That is not decoration: Anek's digits are proportional, so a column of figures set in it does not align.

Anek Latin

Anek Latin. Every non-code level: display, h1, h2, h3, body, body-sm, caption. CoForge is single-family for prose (brand.md §4).

Source Code Pro

Code and token values. Source Code Pro, selected on measurement [ART-007 § Optical pairing] — its x-height ratio is 0.486 against Anek Latin's 0.488, a 0.4% difference. Inline code sits inside body text, so a mismatched x-height reads as a size change mid-sentence and invites a compensating size nudge that then breaks alignment in tables. The nearest rival was 14x further off. Not a brand gesture — a face chosen to be unnoticeable next to the one that is.
