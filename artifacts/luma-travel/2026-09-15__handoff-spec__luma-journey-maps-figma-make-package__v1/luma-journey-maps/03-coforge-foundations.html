Foundations

Colour, type, spacing, radius, elevation, and motion. The complete L1 foundation layer — everything a screen, report, or dashboard is built from.

1 — Colour

Six roles. Colour names describe function, never hue.

Ground #eeece6 Default page surface
Ink #041222 Default text + marks
Ink 2 #525252 Secondary text, captions
Coral #f15b40 Accent — fills + large CTA only
Coral Text #b03822 Coral as text — separate role
Rule #c6c6c6 Dividers, borders
White #ffffff Raised surfaces — cards, nav
✓ DO

Use coral to fill shapes, mark the wordmark, draw rules, back large-type CTAs, and colour bar chart marks.

✗ DO NOT

Use coral as body text, captions, labels, table values, or any text below large-text size on any ground. It fails AA at 2.82:1.

5 — Elevation

Single soft shadow. One depth at a time. Shapes float, not stack.

shadow-0 — Resting

No shadow. Most elements.

shadow-1 — Raised

Cards, floating nav. 0 2px 6px ink 12%.

shadow-2 — Modal

Modals, dropdowns. 0 8px 24px ink 18%.

8 — Critical rules for Figma Make

These constraints are non-negotiable. Breaking them breaks the brand.

✓ DO — page background

Use #eeece6 (Ground) as the default page and document surface.

✗ DO NOT

Use #ffffff as the page background. White is only for raised surfaces (cards, modals).

✓ DO — coral

Fill shapes with coral. Back CTAs with coral when the label is large type. Mark charts and wordmarks.

✗ DO NOT

Put body text, labels, captions, or table values in coral. 2.82:1 contrast fails AA for any text size below 18pt bold / 24pt regular.

✓ DO — ink

Use #041222 (deep navy) as the default text and icon colour.

✗ DO NOT

Use pure black (#000000). It is not in this system.

✓ DO — numbers

Apply font-variant-numeric: tabular-nums to every element that may carry a number.

✗ DO NOT

Leave tabular-nums as optional. Anek Latin's digits are proportional — columns will visibly misalign without it.

✓ DO — one accent

One hot accent in the UI chrome. Secondary hues live only in illustration and chart marks.

✗ DO NOT

Add a second competing accent colour to the interface. It divides emphasis instead of adding it.

✓ DO — texture

Flat fills. One soft shadow for elevation. Shapes float.

✗ DO NOT

Use gradients, glassmorphism, noise, blurs, or gradient meshes. The interface layer is entirely flat.
