   pattern invented here.

## Design decisions worth preserving

- **Two-tier citation** (pain vs. opportunity, different source, different citation) — already logged in
  `context/luma-travel.md`; repeated here because it's the single highest-value pattern to carry into whatever
  journey map or opportunity-adjacent artifact comes next.
- **Verify against the actual file, not the artifact's own description of itself.** `unzip -l` before trusting
  a README; `grep`/`diff` before claiming byte-identity; a live browser click before claiming an interaction
  works. Every check in this chain that mattered was a command run against the artifact, not a claim read from
  its own manifest.
- **Canonical foundations, reused not regenerated.** ART-040's `02-`/`03-` files are copies of
  `design-system/for-figma-make/`, not new authorship — this is what "1:1 migration and reproduction
  consistency" (the user's own phrase) actually requires: one source, copied, not several versions that drift.
- **Name what's owed.** Gate A unsigned, a defect found in a sibling artifact, an arithmetic figure corrected
  from its own first draft — none of these were hidden to make this report read cleaner.
