# ADR-014 — Analytics: a joiner, not an instrument

**Status:** Accepted · 2026-08-27

## Context

The blueprint (§11.2) and ADR-005 specified analytics — five portfolio metrics, an eval
delta, autonomy counters. **None of it had an implementation**, and the readiness audit did
not look for it. The gap-finder had a gap; it surfaced only because Raquel asked.

Third "named but empty layer" found in two days, after CI (ADR-008) and Gate B's Bash bypass.

## The finding that shaped the design

The data already existed in three places and nothing joined them:

| Source | Carries |
|---|---|
| `~/.claude/projects/<slug>/*.jsonl` | tokens per turn, tool and skill usage — **721 turns already recorded** |
| `validation/reports/*__system-audit.md` | gate outcomes including skips |
| `artifacts/_registry.json` | what was produced, from which inputs |

**No telemetry infrastructure was needed.** OTLP would have been a second instrument measuring
what was already on disk. Deferred to Build Stage 5, and only if more than one person uses this.

## Decision

**`metrics.schema.json` first, collector second.** Defining the record shape before measuring
is the same argument as the component contract: without a schema, every measurement is invented
ad hoc and nothing can be compared across runs.

**`collect-metrics.py` is a joiner.** It reads the three existing sources and emits one run
record per day plus a rollup. It creates no new instrumentation.

**Wired into the Stop hook.** Analytics is a by-product of work, never a chore after it.
Everything hand-maintained in this repository has drifted — the correction log is complete only
because I remembered, and the autonomy tally has never been written to. Same rule as
`_registry.json` and `.ai/index.json`: generated by scanning, never hand-edited.

## Privacy — load-bearing, because the repo is public

Transcripts hold the entire conversation. The record must carry **counts and identifiers only**.

- A **privacy check runs before every write** and refuses to emit if any value contains a
  newline or exceeds 64 characters — the shape of prose, not of a metric.
- `.gitignore` excludes `*.jsonl` outright; `validation/metrics/*.json` is explicitly re-included.
- The schema sets `additionalProperties: false` throughout, so a future change cannot quietly
  widen what is captured without editing the schema first.

## What it reports

Turns · duration · tokens (input, output, cache read, cache creation, **billable**) · tools ·
skills · artifacts by type and status · **tokens per artifact** · gate outcomes with **skipped
as a first-class count** · corrections · ADR/agent/type counts · L1, L2 and workflow readiness.

First record: **727 turns · 1,290,423 billable tokens · 4 artifacts · gates PASS · 1 skipped.**

Cache figures are reported separately from billable because they dominate volume (319M) and
would otherwise make the cost figure meaningless.

## Not built yet, deliberately

- **Autonomy counters** (Phase B) — graduation and demotion remain prose. They need artifacts
  flowing through validation before there is anything to count.
- **Skill analytics** (Phase C) — no skills exist yet. Blocked until Wave 3, at which point
  ADR-005's eval delta finally gets a denominator.
- **OTLP** (Phase D) — Build Stage 5, only at multi-person scale.

## Consequence

Readiness layer 8 moved from 2/8 to 5/9. L2 rose 27% → 38%. The score moved because the layer
became real, not because the measurement was relaxed.
