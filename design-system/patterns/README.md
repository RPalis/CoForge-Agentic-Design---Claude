# Patterns — empty by design, not by neglect

A **pattern** is a validated multi-component structure: a form layout, an empty state,
a filter-and-results pairing. Distinct from a component (one thing) and from a template
(a whole page).

Nothing lives here yet, and nothing should until L2 components exist — a pattern is
composed *of* components, so authoring patterns first would mean inventing the very
vocabulary `component-index.json` is supposed to constrain.

Entry is by promotion only: a `pattern-spec` artifact, human approval, recorded as an
ADR. Same membrane as components (`CLAUDE.md` → Boundaries).

Unblocked by: ADR-013 link 1 (adapter #1).
