# Templates — empty by design, not by neglect

A **template** is a whole-page structure assembled from patterns and components —
a dashboard shell, a report layout, an article page.

Nothing lives here yet, and nothing should until patterns exist. A template composed
of patterns that do not exist is a wireframe with extra steps.

Entry is by promotion only, same membrane as components and patterns.

Unblocked by: `design-system/patterns/`, which is unblocked by ADR-013 link 1.
