# Checklist — component-spec

**Stage:** develop · **Owner:** `screen-producer`

> PROPOSAL for a new component. Promotion-only into the index.

## Gate B — automatic (blocks)

- [ ] Artifact is a directory named `YYYY-MM-DD__component-spec__<slug>__v<N>`
- [ ] `manifest.json` present and valid
- [ ] `validation.md` present (this file, filled in)
- [ ] Every `[E-nnn]` citation resolves in `research/evidence-ledger.json`
- [ ] No raw hex / no raw px where the artifact is visual

## Type-specific hard rules

- [ ] Marked as a PROPOSAL. Does not modify component-index.json.
- [ ] States when NOT to use, not only when to use.
- [ ] Names the existing component it is NOT a duplicate of.

## Gate A — human review

- [ ] Claims labelled `Evidenced` / `Inferred` / `Assumption`
- [ ] Assumptions block present and visible
